# 1st Look Garments — Video Assets Directory

This folder contains the video footage for the **"THE ART OF DRESSING WELL"** showcase section on the homepage.

### Default Video File:
- File name: `fashion-showcase.mp4`
- Optimal format: MP4 (H.264 video codec, AAC audio or muted)
- Recommended resolution: 1080p (1920x1080) or 720p (1280x720)
- Optimized for web streaming (fast start / moov atom at beginning)

### How to use your actual shop footage:
1. When you record or receive your official store footage (or garment detail video), save it as `fashion-showcase.mp4`.
2. Replace this file at: `public/assets/videos/fashion-showcase.mp4`.
3. The website will immediately load your new video file while preserving all controls, mobile responsiveness, and luxury layout!
